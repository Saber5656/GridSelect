# Code of Conduct

GridSelect aims to be a focused and respectful open source project. Everyone
who participates in issues, pull requests, reviews, discussions, or related
project spaces is expected to help keep the environment constructive.

## Expected Behavior

- Be respectful and assume good intent while still being precise.
- Keep feedback about the work, not the person.
- Welcome newcomers and explain project context when it helps.
- Respect the project scope, especially the macOS-first pre-alpha MVP boundary.
- Avoid sharing private information, credentials, or security-sensitive details
  in public project spaces.

## Unacceptable Behavior

- Harassment, insults, threats, or sustained disruptive behavior.
- Discriminatory language or conduct.
- Publishing someone else's private information without permission.
- Posting exploit details or vulnerability instructions in public issues.
- Repeatedly pushing off-scope work after maintainers have clarified the
  project boundary.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block users, or
take other reasonable moderation actions when behavior harms the project space.

If you need to report a conduct concern, contact the maintainer `@Saber5656`.
For vulnerabilities, use the process in [SECURITY.md](SECURITY.md) instead of
public issue details.
